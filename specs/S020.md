# S020: Dedicated apply tool

## Title
Dedicated apply tool

## Spec Summary
Add a first-class `apply` MCP tool for running `git apply`, plus script, documentation, and regression test coverage.

## Spec Goal
Expose patch application as a dedicated git-control operation while preserving the generic `run_git` path for allowlisted git commands.
